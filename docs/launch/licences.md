# Licence check

Checked on 2026-11-03 against the licence of every one of the 730 packages installed in the app and its three engines (`node_modules`, `studio/remotion`, `studio/hyperframes`, `studio/sound`), the licence files inside them, and each licensor's own page. The repo itself has no licence file, and `package.json` says `"private": true`. Run the check again after adding packages (script at the end).

## What blocks selling

### 1. The sound engine is AGPL-3.0

`@strudel/core`, `@strudel/draw`, `@strudel/mini`, `@strudel/tonal`, `@strudel/transpiler`, `@strudel/webaudio`, `superdough`, `supradough`, `@kabelsalat/core`, `@kabelsalat/lib` and `@kabelsalat/web`, all `AGPL-3.0-or-later`, all in `studio/sound` (used by `studio/sound/engine.js` and `scripts/studio/sound.mjs`).

AGPL applies whether the studio is sold as a download or run as a website. Its network clause exists to close the "it only runs on our server" route, so a SaaS doesn't escape it. Selling it closed would mean publishing the source of at least the sound engine, and arguably the whole studio, under AGPL. The README already notes this for use outside Aerchain.

Ways out:

1. Write the music in Tone.js (MIT), which the same engine already uses for hits and effects. Recommended.
2. Open-source the studio under AGPL, and sell hosting, support or kits instead.
3. Run the sound engine as a separate AGPL program the studio only calls. This is a grey area; only do it on a lawyer's advice.

### 2. GSAP

It's copied into every HTML film (`studio/starters/html/assets/vendor/gsap.min.js`), and HyperFrames' runtime looks for `window.gsap`.

GSAP is free, commercially too, but its licence (https://gsap.com/community/standard-license/) lists as a Prohibited Use: "any implementation and/or use of GSAP Products in tools that allow users to build visual animations without code that encourages, induces, or materially assists in creating a solution that competes with Webflow's visual animation building capabilities". It defines Competitive Products as "any software, tool, or service that enables users to create, edit, or manage animations through a visual interface or builder similar to Webflow". A studio where people make animations by asking, with a timeline and controls, sits close to that line.

Ways out: Webflow's written consent, or move films off GSAP. See [gsap-to-motion.md](gsap-to-motion.md).

### 3. Remotion

Every `remotion` and `@remotion/*` package is under the Remotion License (`studio/remotion/node_modules/remotion/LICENSE.md`), source-available rather than open source. From https://www.remotion.dev/docs/license/faq:

- Free for individuals and for-profit companies with up to 3 employees, "even if you set up an automation, launch a SaaS, or are using it commercially".
- Otherwise a Company License. For automations, "Remotion for Automators" costs "$0.01 per render, with a minimum spend of $100/month".
- "Your customers can be other companies and they don't need to have a Company License."
- "Allowing end-users to edit the Remotion code is also permitted if the code was initially generated by your service. However, it is not allowed to let users bring or upload their own Remotion code to your service for rendering." So no "import your own Remotion project" feature.
- Dropping the Remotion engine is also an option: HyperFrames (Apache-2.0) and fframes (MIT) remain.

### 5. Aerchain's material

The brand kit (`studio/brands/aerchain`: logos, guideline, rules), the `aerchain-*` skills and the Aerchain wording in prompts are Aerchain's. Take them out of a product build. The font in that kit, Bricolage Grotesque, is OFL and can stay.

## Running the check again

From the repo root. It lists every package whose licence isn't plainly permissive:

```bash
node --input-type=module -e '
import { readdirSync, readFileSync, existsSync } from "node:fs";
import path from "node:path";
const roots = ["node_modules", "studio/remotion/node_modules", "studio/hyperframes/node_modules", "studio/sound/node_modules"];
const seen = new Map();
const walk = (dir, root) => {
  if (!existsSync(dir)) return;
  for (const name of readdirSync(dir)) {
    if (name.startsWith(".")) continue;
    const full = path.join(dir, name);
    if (name.startsWith("@")) { walk(full, root); continue; }
    const pkg = path.join(full, "package.json");
    if (!existsSync(pkg)) continue;
    try {
      const p = JSON.parse(readFileSync(pkg, "utf8"));
      const lic = typeof p.license === "string" ? p.license : p.license?.type ?? "(none)";
      if (p.name) seen.set(`${p.name}@${p.version}`, { lic, root });
    } catch {}
    walk(path.join(full, "node_modules"), root);
  }
};
for (const r of roots) walk(r, r);
const ok = /^\(?(MIT|ISC|Apache-2\.0|BSD-2-Clause|BSD-3-Clause|0BSD|BlueOak-1\.0\.0|CC0-1\.0|Unlicense|Python-2\.0|CC-BY-4\.0|MIT-0|WTFPL)( (OR|AND) (MIT|ISC|Apache-2\.0|BSD-2-Clause|BSD-3-Clause|0BSD|CC0-1\.0|Unlicense|CC-BY-3\.0|CC-BY-4\.0|MIT-0|WTFPL))*\)?$/;
console.log(`${seen.size} packages`);
for (const [k, { lic, root }] of [...seen].sort()) if (!ok.test(lic)) console.log(`${lic.padEnd(28)} ${k}  [${root}]`);'
```
